# Project screenshot slots

Main cover screenshots (shown in the project cards):

- `dovia-cover.png`
- `afyapulse-cover.png`
- `somamap-cover.png`
- `campuscare-cover.png`

Optional screenshots (shown inside each project's expanded **Behind the build** section):

- `dovia-01.png`, `dovia-02.png`
- `afyapulse-01.png`, `afyapulse-02.png`
- `somamap-01.png`, `somamap-02.png`
- `campuscare-01.png`, `campuscare-02.png`

Export genuine PNG files using these **exact filenames**. Don't rename a JPG file's extension without converting its format.

Suggested covers: 1600 x 1000 (landscape) for web projects; CampusCare can use a portrait mobile screenshot. Optional screenshots can be landscape or portrait. Keep them readable and compressed (~200–700 KB each where feasible).

If a screenshot isn't added, the corresponding original illustrated preview remains on the card; absent optional screenshots won't display broken icons or empty galleries.
