# Portfolio feature guide

## Source
The live portfolio is maintained in `public/original.html`, with separate assets under `public/assets/`.

## Features
- Project cards, expandable case studies and image lightbox.
- GitHub contribution chart and public repository feed. These rely on third-party services and may be unavailable offline.
- Accessible command terminal: help, about, projects, skills, github, contact, clear.
- Engineering notes (curated summaries, not links to nonexistent posts).
- Timeline, contact links and progressive scroll reveals.

## Editing
Keep the dark/lime palette: #10110e, #1b1d17, #d7fc70. Verify links and screenshot paths before publishing. Do not publish fabricated statistics. Respect reduced-motion preferences.
