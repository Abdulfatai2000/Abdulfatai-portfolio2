# Abdulfatai Portfolio

A monochrome, responsive software engineering portfolio built with Next.js App Router, TypeScript, and CSS.

## Setup
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Features
- Responsive mobile navigation
- Animated hero, sections, and interactions
- Projects, timeline, technology proficiency, and contact sections
- Print-ready résumé route at /resume
- SEO metadata and accessible interactions

## Customize
Update `src/lib/data.ts` with your current experience, project links, and contact information. Update the resume route for a polished printable CV and add a real CV PDF to `public/cv.pdf` if you prefer direct PDF downloads.

## Deploy
Import the repository into Vercel and choose Next.js; no secrets required.

## Commit workflow
Every feature and adjustment is committed independently with clear messages.
