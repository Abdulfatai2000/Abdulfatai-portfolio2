# Abdulfatai Portfolio

The original lime-monochrome **ABTech Portfolio** has been recovered and preserved in this repository, with the displayed brand renamed to **Abdulfatai**.

## Source of truth
- `public/original.html` — recovered original HTML, CSS, JavaScript, original project stories, responsive menu, circular skill indicators, and footer.
- `next.config.ts` — serves the recovered page at `/`.
- The original public reference: https://codewande-portfolio.clean-toad-9167.chatgpt.site/

## Run locally
```bash
npm install
npm run dev
```
Visit http://localhost:3000.

## Deploy
Import `Abdulfatai2000/Abdulfatai-portfolio2` into Vercel as a Next.js repository. Your domain will show the restored portfolio at the root.

## Important
The HTML represents the original published website, not the original editable React component source. The original CV download links reference the previously published site's PDF. Verify these links after deploying and add the CV locally later if needed.

### Design preservation
Do not re-create the visual design from memory. Edit `public/original.html` when making visual changes, and preserve `#10110e`, `#1b1d17`, and `#d7fc70` unless explicitly asked to change the palette.
